## 📖 About The Project

This is a responsive multi-page profile website showcasing major 20th-century historical leaders.

The project focuses on:

- Clean UI design
- Responsive layout
- Performance optimization
- Semantic HTML structure
- GitHub Pages deployment

Built entirely using **pure HTML and CSS** without frameworks.

---

## ✨ Features

- 📱 Fully responsive (mobile-first approach)
- 🖼 Optimized WebP images
- ⚡ Performance-focused structure
- 🎨 Custom theme styling
- 🔤 Google Font integration
- 🧩 Multi-page navigation
- 🧭 Semantic HTML5 layout

## ⚡ Performance Optimizations

This project includes:

- Responsive image sizing
- Fixed image dimensions (prevents layout shift)
- Optimized Largest Contentful Paint (LCP)
- Deferred font loading
- Lightweight CSS structure
- Reduced render-blocking resources

---

## 🚀 Deployment

Deployed using **GitHub Pages**.

To deploy your own version:

1. Fork or clone the repository
2. Push to your GitHub account
3. Go to **Settings → Pages**
4. Select branch (`main`)
5. Save and wait for deployment
